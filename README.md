# Практическая работа №16 — Физика 2D

Проект для Unity 6. Сцена `Assets/Scenes/MainScene.unity` содержит панель управления, физические объекты, платформу и триггерную зону. Ассеты ScriptableObject, Physics Material 2D и префабы находятся в папке `Assets`.

## Запуск

1. Откройте папку `PR16_Physics2D` через Unity Hub (версия 6000.2.8f1 или новее). При первом импорте дождитесь компиляции и создания сцены.
2. Откройте `Assets/Scenes/MainScene.unity` и нажмите Play.
3. Выберите тип объекта в правом списке, затем нажмите «Создать объект». Объект появится над платформой.

Если проект уже открыт в Unity во время обновления, закройте и снова откройте его, чтобы Unity перечитала список модулей. Если сцена или ассеты были удалены, используйте меню **PR16 → Собрать сцену и ассеты**.

## Управление и демонстрация

- **Создать объект** или `Space` — создать выбранный объект; без выбора тип выбирается случайно.
- **Гравитация** или `G` — Земля → половина → Луна → невесомость → антигравитация.
- **Очистить** или `Delete` — удалить созданные объекты.
- Щелчок по объекту — приложить импульс.
- Столкновения и вход/выход из триггера отображаются в Console.

## Состав проекта

- `PhysicsObjectData`, `PhysicsConfig`, `ObjectDatabase` — данные и конфигурация в ScriptableObject.
- `PhysicsObjectFactory`, `PhysicsObjectComponent`, `TriggerZone`, `PhysicsController` — создание объектов, физические события, триггеры и UI.
- `Assets/Editor/PR16ProjectSetup.cs` собирает сцену, связи и ассеты из меню Unity.

Скрипты восстановлены по изображениям кода, встроенным в исходный DOCX. В Unity 6 применены соответствующие имена damping-параметров Rigidbody2D.
